# Django Dev Environment Proof
*A demonstration of implementing developer environment controls on a Django project.*

gitignore:
  - holds files to hide from github on upload
  - eliminates redundant packages in ecosystem

requirements.txt:
  - holds package names and versions for installation

environs:
  - holds settings for current environment

## Deliverable
The production version of the project now exists as a github repository.

Clones must specify a secret key.

Supporting packages must be installed after downloading using the command:

`pip install -r requirements.txt`
